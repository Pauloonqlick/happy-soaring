Como usar

  1. Carrega em Abrir pasta do projeto e escolhe a pasta HappySoaring.
  2. Autoriza o browser a ver e editar os ficheiros.
  3. Edita nome, género, grátis e duplicado. Carrega em Gravar.

Só funciona em Chrome ou Edge — usa a API de ficheiros que o Firefox e o Safari não têm. Esta página não envia nada para lado nenhum: escreve diretamente no teu disco.

Marcar Duplicado não apaga nada. Só assinala a faixa. A remoção (preview + WAV) é feita depois, com confirmação, e os ficheiros vão para uma pasta de recuperação.

Géneros

Muda o nome aqui e ele é alterado em todas as faixas desse género. Também podes escrever o género direto na tabela — se for novo, é criado.
