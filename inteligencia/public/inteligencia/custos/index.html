Custos

Quanto custam a conta Cloudflare e a DataForSEO, quanto falta para passar do que o plano da Cloudflare inclui e quanto dura o saldo da DataForSEO. Na Cloudflare os limites são da conta inteira — contam todos os Workers, bases, buckets e namespaces, também os que não são do site — e o incluído renova-se no dia do mês em que o plano foi subscrito. É uma estimativa feita a partir das estatísticas da Cloudflare e do saldo da DataForSEO; as faturas oficiais são as delas.

A carregar…

Falta ligar o módulo às estatísticas da Cloudflare

O módulo precisa de um token só de leitura. Faz-se uma vez, no painel da Cloudflare — o valor do token nunca passa por aqui nem pelo Claude.

  1. No painel da Cloudflare: Manage account → Account API tokens → Create token → Create custom token.
  2. Nome: hs-inteligencia-custos. Permissões: Account · Account Analytics · Read e Account · D1 · Read (esta só serve para mostrar o nome das bases).
  3. Criar e copiar o token.
  4. Em Workers & Pages → hs-inteligencia → Settings → Variables and Secrets → Add: tipo Secret, nome CF_ANALYTICS_TOKEN, valor = o token. Guardar.

A partir daí os consumos são lidos de hora a hora, ao minuto 08.
